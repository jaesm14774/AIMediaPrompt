# Auto Trend Scout
自動偵測當日台灣熱門趨勢，生成可立即使用的創意方向清單。

## 核心目標

解決「使用者主題模糊 → LLM 靠訓練記憶撈舊梗」的根本問題。透過即時 WebSearch，讓每次生成的 prompt 都能搭上當下最有傳播力的話題波段。

## 使用方式

```bash
/auto-trend-scout                     # 全自動偵測台灣今日趨勢
/auto-trend-scout --focus "科技"      # 聚焦特定領域的趨勢
/auto-trend-scout --platform fb       # 以特定平台受眾偏好過濾
/auto-trend-scout --type video        # 優先找適合影片格式的趨勢
```

**典型使用情境：**
- 不確定今天要做什麼主題時，先跑這個
- 想讓內容有時效性、搭話題熱度時
- `/full-pipeline --auto-trend` 時自動呼叫本 skill

## 執行流程

### Step 1：多源趨勢抓取（平行搜尋）

同時搜尋以下來源，抓取今日（或近 48 小時內）最熱門的話題：

**搜尋指令（依序執行，每項用 WebSearch）：**

```
1. Google Trends 台灣今日：
   搜尋："Google Trends Taiwan trending today 2026"
   或："台灣 Google 熱搜 今天 site:trends.google.com.tw"

2. 台灣社群熱門事件：
   搜尋："台灣 今天 熱門話題 {今日日期}"
   搜尋："Taiwan trending news today {today's date}"

3. 娛樂 / IP 相關：
   搜尋："台灣 熱門 動漫 遊戲 話題 {本月}"
   搜尋："Taiwan viral meme social media {today's date}"

4. 節日 / 時節性：
   根據今日日期自動判斷：
   - 距離最近的節日（母親節、中秋、聖誕、跨年等）
   - 本週/本月特殊紀念日或年度事件
   - 當季氣候或現象（梅雨、颱風、賞花等）

5. AI / 創作圈動態：
   搜尋："AI art trend viral {本週}"
   搜尋："Gemini AI image viral week"
```

### Step 2：話題品質篩選

對每個搜尋結果，快速評估以下條件，**保留符合 3 項以上的話題：**

| 條件 | 說明 |
|------|------|
| ✅ 時效性 | 這 48 小時內出現或爆發 |
| ✅ 視覺潛力 | 能被轉換成強烈視覺概念 |
| ✅ 普遍共鳴 | 目標受眾（台灣 25-45 歲）都能秒懂 |
| ✅ 非政治 / 非敏感 | 可安全用於 AI 藝術創作 |
| ✅ 有梗可延伸 | 不只是新聞事件，有情感或幽默切入空間 |

**自動剔除：**
- ❌ 純政治議題
- ❌ 悲劇 / 災難新聞（不適合創意化）
- ❌ 已在 Prompt 資料夾出現過的高度相似主題

### Step 3：創意角度轉化

對每個通過篩選的話題，**必須找出至少 2 個「非顯而易見」的創意切入角度**：

**轉化規則：**
- ❌ 禁止直接用話題本身當 prompt（如「颱風來了」→ 直接畫颱風）
- ✅ 要找出話題背後的情緒、衝突或反差，再轉化為視覺概念

**轉化範例：**
```
話題：「最近氣溫突然飆升到35度」
❌ 普通角度：畫一個人熱到快暈倒
✅ 創意角度 A：Tiny Epic × Emotional Weather → 太陽神在辦公室開了太猛的暖氣，
              全地球員工集體投訴，史詩級勞資糾紛
✅ 創意角度 B：Absurd Professionalism → National Geographic 紀錄台灣人在
              35度高溫中以「專業姿態」等捷運的珍貴野生行為
```

## 時節性日曆（自動偵測）

每次執行時，根據今日日期自動判斷當下是否有時節話題可用：

| 月份 | 常見時節性話題 | AI 創作潛力 |
|------|-------------|-----------|
| 1 月 | 跨年、新年願望崩壞、寒流 | ⭐⭐⭐⭐⭐ |
| 2 月 | 情人節、元宵、年假結束 | ⭐⭐⭐⭐⭐ |
| 3 月 | 春分、花粉、考試季開始 | ⭐⭐⭐ |
| 4 月 | 清明、愚人節、梅雨季前 | ⭐⭐⭐⭐ |
| 5 月 | 母親節、五月天（熱天）、畢業季 | ⭐⭐⭐⭐⭐ |
| 6 月 | 端午、畢業典禮、梅雨 | ⭐⭐⭐⭐ |
| 7-8 月 | 颱風、暑假、鬼月 | ⭐⭐⭐⭐⭐ |
| 9 月 | 開學、中秋、鬼月結束 | ⭐⭐⭐⭐ |
| 10 月 | 雙十國慶、萬聖節、秋季 | ⭐⭐⭐⭐ |
| 11 月 | 雙十一購物節、天氣轉涼 | ⭐⭐⭐⭐ |
| 12 月 | 耶誕節、跨年倒數、年末崩潰 | ⭐⭐⭐⭐⭐ |

**時節性話題優先於搜尋結果**，因為受眾的情緒共鳴已預先加熱。

## 與其他 Skill 整合

```
auto-trend-scout
      │
      ├──→ /generate-prompt "{推薦話題}" 
      │       └──→ 自動帶入查重 + 混搭機制
      │
      ├──→ /research-keyword (Route C 自動觸發)
      │       └──→ 深化趨勢話題的 IP / 角色研究
      │
      └──→ /full-pipeline --auto-trend
              └──→ 完整自動化：趨勢偵測 → 生成 → 媒體 → 上傳
```

## 注意事項

- 每次執行搜尋結果受網路即時性影響，建議每天只跑一次取最新資料
- 若 WebSearch 無法取得今日資料，退回「時節性日曆」自動推薦
- 輸出的創意方向僅供參考，最終是否使用由使用者或 `/generate-prompt` 的查重機制決定
- 所有輸出使用**繁體中文為主、英文輔助**的雙語格式
