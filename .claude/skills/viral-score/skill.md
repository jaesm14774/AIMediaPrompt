# Viral Score

評估 **Post 成品**的病毒傳播潛力。聚焦於文案、視覺、平台策略——與 `/evaluate-prompt`（評估 Prompt Template 品質）互補，不重複。

## S 級定義（與其他技能統一）

**S 級不是「貼文完整」、「圖很漂亮」、「有潛力」。S 級必須讓人停下來，並自然產生分享衝動。**

對 `viral-score` 來說，S 級至少要同時成立：

- 第一眼會停滑
- 文案或畫面會留下記憶點
- 觀眾會想 tag 朋友、轉發或收藏
- 整體不是安全牌，不是「還不錯但少一擊」

**以下情況一律不能算 S 級：**

- 只是資訊完整
- 只是圖美
- 只是 hook 合格
- 只是可愛或溫馨
- 只是看起來像高分模板文，卻沒有強烈反應

## 定位分工

| Skill | 評估對象 | 階段 | 核心問題 |
|-------|---------|------|---------|
| `/evaluate-prompt` | Prompt Template | Phase 1 | 這個 prompt 能產出好作品嗎？ |
| `/viral-score` | **Post 成品** | Phase 3 | 這篇發布出去會爆嗎？ |

## 使用方式

```bash
/viral-score [Post 檔案] [選項]
```

**參數說明：**
- `[Post 檔案]`：Post 檔案路徑
- `--image <路徑>`：配圖路徑（可選）
- `--type <類型>`：`image`（預設）或 `video`，切換對應評估子維度
- `--platform <平台>`：目標平台 `fb`（預設）、`ig`、`x`
- `--detailed`：顯示詳細評估報告

**範例：**
```bash
/viral-score "Post/Test/2026-03-21-卡比闖入中世紀油畫.md"

/viral-score "Post/Test/2026-03-21-卡比闖入中世紀油畫.md" --image cover.png --platform fb

/viral-score "Post/2026-03-31-偶像誕生音樂節奏-蛋糕舞台演唱會.md" --type video --detailed
```

## 評估維度

### 五大維度（重新設計）

| 維度 | 權重 | 說明 |
|-----|-----|------|
| **文案鉤子力** | 25% | Hook 標題、互動問題、敘事節奏——驅動停留與互動的核心 |
| **視覺衝擊力** | 20% | 成品圖/影片是否讓人停下滾動 |
| **情感共鳴度** | 15% | 是否觸發強烈情緒（驚喜、好奇、懷舊、認同） |
| **可分享性** | 20% | 觀眾是否想 tag 朋友、轉發、收藏 |
| **平台適配度** | 20% | 演算法偏好 + Hashtag 策略 + 格式匹配 |

### 評分等級

| 等級 | 分數 | 說明 | 建議行動 |
|-----|-----|------|---------|
| **S 級** | 9.0-10.0 | 極高病毒潛力 | **唯一通過標準**，立即發布 |
| **A 級** | 8.0-8.9 | 高潛力 | 未達發布標準，依提升指南優化 |
| **B 級** | 7.0-7.9 | 中等潛力 | 不發布，建議重新生成 |
| **C 級** | 6.0-6.9 | 低潛力 | 不發布，需大幅修改 |
| **D 級** | <6.0 | 不建議發布 | 不發布，需重做 |

### 木桶效應規則

加權平均前，先檢查短板：

| 條件 | 懲罰 |
|-----|------|
| 任一維度 < 5.0 | 整體上限 **C 級** |
| 任一維度 < 7.0 | 整體上限 **A 級** |
| 文案鉤子力 < 7.0 | 整體上限 **B 級**（文案是傳播核心） |

### S 級硬門檻

加權總分 **≥ 9.0** 還不夠，必須同時滿足：

- 文案鉤子力 **≥ 9.0**
- 視覺衝擊力 **≥ 8.5**
- 可分享性 **≥ 9.0**
- 不得出現「會滑過」「只適合粉絲」「只有可愛」這類核心保留意見
- 評估者必須能清楚說出：觀眾為什麼會停、為什麼會想分享、這篇貼文最強記憶點是什麼

若只是成熟、穩定、漂亮、完整，但不夠強，一律降為 **A 級**。

## 執行流程

### Step 1: 讀取內容

1. **讀取 Post 檔案**：
   - 提取 Hook 標題（中英文）
   - 提取 Prompt Template 區塊
   - 提取 Key Parameters / Pro Tips / Try This Variation
   - 提取互動問題（CTA）
   - 提取 Hashtag Block
   - 判斷內容類型（image / video）

2. **讀取媒體**（如果提供）：
   - 圖片：分析構圖、色彩、視覺元素
   - 影片：分析前 3 秒 Hook、故事弧線、節奏感

### Step 2: 分析各維度

#### 2.1 文案鉤子力 (25%) — 傳播核心

**評估元素**：

- **Hook 標題**：是否製造好奇心缺口（Curiosity Gap）？
  - ✅ 好：「這幅文藝復興油畫在博物館掛了幾百年——圖中那位粉嫩貴族到底是誰？」
  - ❌ 差：「Kirby 風格的油畫 Prompt 分享」
- **敘事節奏**：Hook → 情境鋪墊 → Template → 教學 → CTA，是否有起承轉合？
- **互動問題（CTA）**：是否低門檻高回饋？
  - ✅ 好：「如果你是文藝復興畫家，你會怎麼記錄這位客戶的名字？」（具體、有趣、門檻低）
  - ❌ 差：「你覺得好看嗎？」（是/否問題，無法引發討論）
- **中英雙語品質**：英文是否自然、有獨立吸引力（非機翻感）？
- **Pro Tips / Variation 區塊**：是否提供進階玩法，延長停留時間？

**評分指標**：
- 10 分：Hook 製造強烈好奇心，CTA 會引發留言串，整體敘事讓人讀完
- 7-9 分：Hook 不錯但 CTA 普通，或敘事有一處斷層
- 4-6 分：Hook 平淡，CTA 是是非題，整體像說明書
- 1-3 分：無 Hook、無 CTA，純技術堆砌

#### 2.2 視覺衝擊力 (20%)

根據 `--type` 切換子維度：

**Image 模式**：
- **停滑力**：在 Feed 中是否一眼就會停下來？
- **構圖**：焦點清晰？有視覺引導？
- **色彩對比**：是否有吸引人的色彩張力？
- **細節層次**：近看是否有驚喜細節？

**Video 模式**：
- **前 3 秒 Hook**：開場是否有足夠的視覺衝擊讓人不滑走？
- **故事弧線**：是否有完整的起承轉合（即使只有 7 秒）？
- **節奏感**：畫面節奏是否匹配情緒（不拖沓、不混亂）？
- **結尾記憶點**：最後一幀是否讓人想重看或截圖？

**評分指標**：
- 10 分：一眼驚艷（圖）/ 前 3 秒就被抓住（影）
- 7-9 分：吸引人，願意多看 / 看完
- 4-6 分：普通，不會特別注意
- 1-3 分：無聊或混亂，直接滑過

#### 2.3 情感共鳴度 (15%)

**評估標準**：
- **驚喜感**：是否有意想不到的反差或組合？
- **懷舊感**：是否觸發童年回憶或共同經歷？
- **好奇心**：是否讓人想知道「接下來呢？」或「怎麼做到的？」
- **認同感**：是否說出觀眾的心聲？

**評分指標**：
- 10 分：強烈情感觸發，會讓人想分享
- 7-9 分：有情感連結，會記住
- 4-6 分：無特別情感
- 1-3 分：無感或負面情感

#### 2.4 可分享性 (20%)

**評估標準**：
- **Tag 衝動**：看到第一反應是不是「要傳給 XXX 看」？
- **話題性**：是否能引發討論串（不只是「好可愛」）？
- **社交貨幣**：分享這個會讓分享者看起來有品味 / 有趣 / 懂行？
- **實用價值**：Prompt Template 是否容易複製使用，讓人想收藏？

**評分指標**：
- 10 分：會主動 tag 朋友、截圖轉發
- 7-9 分：會轉發或收藏
- 4-6 分：看看就好，不會分享
- 1-3 分：完全沒有分享動力

#### 2.5 平台適配度 (20%)

包含 **演算法匹配** + **Hashtag 策略** 兩個子項。

**演算法匹配（各平台細則）**：

| 平台 | 關鍵演算法偏好 | 最佳實踐 |
|-----|-------------|---------|
| **FB** | 長文互動 > 連結分享；前 3 行決定展開率；留言互動觸發二次推薦 | Hook 在前 3 行完成、CTA 引導留言、圖片方形或橫幅 |
| **IG** | Reels 前 3 秒完播率；Hashtag 可發現性；Carousel 翻頁率 | 正方形 / 9:16、30 個以內 hashtag、首圖強 Hook |
| **X** | 引用轉推 > 純轉推；thread 展開率；即時話題搭配 | 精簡文案 + 強圖、話題標籤、適合引用的金句 |

**Hashtag 策略評估**：

- **覆蓋率**：是否混合大（>100K）、中（10K-100K）、小（<10K）流量標籤？
- **語言多樣性**：是否覆蓋目標受眾語圈（繁中 + 英文 + 日文等）？
- **相關性**：是否與內容主題直接相關（非灌水標籤）？
- **數量**：FB 建議 5-15 個，IG 建議 15-30 個，X 建議 2-5 個

**評分指標**：
- 10 分：完美匹配平台特性，Hashtag 策略精準
- 7-9 分：大致符合，Hashtag 或格式有小調整空間
- 4-6 分：需要調整才適合該平台
- 1-3 分：完全不適合該平台

### Step 3: 計算總分

```
原始分 = (文案鉤子力 × 0.25) + (視覺衝擊力 × 0.20) + (情感共鳴度 × 0.15) + (可分享性 × 0.20) + (平台適配度 × 0.20)

最終分 = min(原始分, 木桶效應上限)
```

### Step 4: 輸出報告

**CRITICAL**：若最終不是 S 級，必須明確寫出 **「為什麼這次不算 S 級」**，不能只給泛泛建議。

## A → S 級提升指南

當分數卡在 8.0-8.9 時，檢查以下清單快速定位瓶頸：

### 文案鉤子力不足（最常見瓶頸）

| 問題 | 快速修復 |
|-----|---------|
| Hook 太直白（「XX Prompt 分享」） | 改用好奇心缺口：提問、懸念、反常識開頭 |
| CTA 是是非題（「你覺得好看嗎？」） | 改用開放式二選一或填空（「你會選 A 還是 B？」「你的版本是__？」） |
| 敘事像說明書 | 在 Template 前加一段情境敘事（虛構場景、第一人稱體驗） |
| 英文像機翻 | 英文另寫，不是翻譯中文——用口語化表達、適當幽默 |

### 平台適配度不足

| 問題 | 快速修復 |
|-----|---------|
| Hashtag 全是大流量標籤 | 混入 3-5 個小眾精準標籤（IP 名 + 風格名組合） |
| Hashtag 只有單一語言 | 加入日文標籤（日本 AI Art 社群活躍度高） |
| FB 前 3 行太長 | 確保 Hook 在 2 行內完成，第 3 行留給懸念或問題 |

### 可分享性不足

| 問題 | 快速修復 |
|-----|---------|
| 只有可愛沒有話題 | 加入「社交實驗」元素（如「傳給朋友問這是什麼時代的畫」） |
| Prompt Template 不好複製 | 確保 code block 格式正確，填空位置用 `[方括號]` 標明 |
| 缺乏進階玩法 | 增加 Try This Variation 區塊，給出 2-3 個延伸方向 |

### 視覺衝擊力不足

| 問題 | 快速修復 |
|-----|---------|
| 圖片缺乏焦點 | 確保有一個主視覺中心，背景不搶戲 |
| 色彩平淡 | 在 Prompt 中加強色彩對比指令 |
| 影片前 3 秒平淡 | 把最強視覺放在第一幕，不要慢熱 |

## 注意事項

- **主觀性**：評分有一定主觀性，僅供參考
- **平台差異**：不同平台偏好差異大，建議指定平台評估
- **趨勢變化**：社群趨勢會變化，評估標準需定期校準
- **A/B 測試**：最終效果還是要看實際發布後的數據
- **與 evaluate-prompt 分工**：不要在 viral-score 重複評估概念創意——那是 evaluate-prompt 的職責
- 在 `full-pipeline` 中，`viral-score` 是硬性關卡，不是純紀錄用途
- 每次評 S 級前，先反問自己：**這篇內容真的會讓人停住、記住、想分享嗎？**
