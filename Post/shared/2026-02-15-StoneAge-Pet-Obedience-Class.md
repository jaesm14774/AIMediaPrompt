💡 **Key Parameters / 關鍵參數解析**

- **don't eat the teacher**：指令清單中的幽默亮點——把「寵物訓練」的荒謬感具象化，觀眾會心一笑 (The punchline in the command list — materializes the absurdity of pet training, viewers chuckle)

- **恐龍班級小細節（dino class details）**：一隻在睡覺、一隻被蟲子分心、一隻已經吃掉鼻尖上的零食——每隻恐龍都有個性，讓「上課」場景有故事感 (One sleeping, one distracted by bug, one already ate the treat — each dino has personality, gives "class" scene storytelling depth)

- **石器道具（Stone Age props）**：獎勵袋、石頭訓練器、本週之星陶土徽章 / 蘆葦哨、敏捷賽道旗、樹皮畢業證書 / 出勤石板、行為圖表、葉子畢業帽——三組道具對應不同教學風格 (Three prop sets: reward pouch + clicker + badge / whistle + markers + diplomas / attendance + chart + caps — each set matches different teaching style)

🎨 **Pro Tips / 專家建議**

❌ 讓恐龍寶寶太乖或太整齊——這不是軍訓，而是「有幾隻在認真、有幾隻在搗蛋」的日常教室感。至少一隻睡覺、一隻分心才對味 (Don't make baby dinos too obedient or整齐 — this isn't military drill, it's "some paying attention, some goofing off" classroom vibe. At least one sleeping, one distracted)

✅ 石板黑板要畫 crude drawings of commands——簡單線條的「坐下」「別動」圖示，像兒童節目教學畫面，才有 instructional charm (Stone blackboard needs crude drawings — simple line art for "sit" "stay" — like children's TV teaching visuals, creates instructional charm)
