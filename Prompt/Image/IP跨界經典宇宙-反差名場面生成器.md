# IP跨界經典宇宙-反差名場面生成器

媒體類型 / Media Type: **image**

## 核心定位 / Core Positioning

這是一個專門生成「知名 IP × 經典史詩文本 / 歷史敘事 / 神話宇宙」反差名場面的高衝擊模板。
This template is built for high-impact crossover scenes that fuse famous IP with classic epics, historical narratives, or mythic worlds.

目標不是單純把角色換衣服，而是把「角色辨識度、原作機制、史詩世界觀、名場面張力」壓進同一張圖。
The goal is not simple cosplay, but a single image that compresses character recognizability, source mechanics, epic worldbuilding, and iconic-scene tension.

## Prompt Template / 提示模板

```text
A premium crossover key visual that merges [IP角色 / IP character] with [經典作品 / classic world or text] through one instantly readable high-contrast premise: [核心錯置規則 / core contrast rule].

Scene concept: [名場面主軸 / signature scene]. The setting is [場景環境 / environment], filled with [世界觀細節 / world details]. The main subject is [主角描述 / main hero description], performing [關鍵動作 / key action], while [配角或群像安排 / ensemble staging] reinforces the scale and narrative.

Visual design rules: preserve the unmistakable identity markers of [IP角色 / IP character], but reinterpret them so they feel native to [經典作品 / classic world]. Emphasize [角色辨識元素 / iconic traits], [力量或能力機制 / power mechanic], and [敘事衝突 / dramatic conflict].

Composition: [構圖方式 / framing]. Lighting: [光線設計 / lighting]. Style: [風格質地 / style]. Emotion: [情緒目標 / emotional goal]. Color palette: [色彩策略 / color palette].

Quality bar: instantly readable focal point, one-second hook, strong silhouette separation, layered foreground-midground-background depth, premium cinematic polish, ultra detailed, no text, no watermark.
```

## 組合邏輯 / Combination Logic

- 第一層是 **IP 識別**：角色輪廓、臉部特徵、代表色、代表能力。
- Layer 1 is **IP recognition**: silhouette, face traits, signature colors, and signature powers.

- 第二層是 **經典文本識別**：時代服飾、武器、建築、地景、儀式感。
- Layer 2 is **classic-world recognition**: costume era, weapons, architecture, landscape, and ritual cues.

- 第三層是 **反差鉤子**：讓觀眾一秒看懂「怎麼會是這個組合」。
- Layer 3 is the **contrast hook**: viewers should understand the absurd yet compelling mashup in one second.

- 第四層是 **名場面動作**：不是靜態合照，而是正在發生的戲劇瞬間。
- Layer 4 is the **signature action beat**: not a static lineup, but a dramatic moment in progress.

## 發文建議 / Publishing Notes

- 這組模板最適合做成「一張主圖 + 10 張變體輪播」或「模板教學 + 精選 3 張成品」。
- This template works best as either a single hero image plus a 10-image carousel, or a tutorial post paired with 3 selected outputs.

- 如果要衝停留率，首圖優先用 `01`、`04`、`07` 這三張，因為一秒辨識度最高。
- For stop-scroll performance, lead with `01`, `04`, or `07`; they have the strongest one-second readability.

- 若未達 S 級，優先修正焦點層級、角色辨識度、與前中後景分離。
- If results miss S-grade, fix focal hierarchy, character recognizability, and foreground-midground-background separation first.
