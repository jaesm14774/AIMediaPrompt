## 使用說明

- **類型**：emotion（情緒型 — 視覺悖論 × 反差萌 × 被看見）
- **核心刺點**：「你見過最古老的眼睛，長在你見過最柔軟的臉上」——所有其他設計都服務於這個視覺悖論的放大
- **關鍵設計邏輯**：
  1. **袍子尺寸荒謬化**：大十倍的袍子把「容器與內容」的落差視覺化——身體越小，智慧越無從收納
  2. **眼神是核心**：用一句「the oldest eyes in the softest face」鎖定記憶點，不分散到多個描述
  3. **時間點整合**：「in the moment you looked up expecting no one, it was already there, having been there the whole time」把「被看見」的驚喜和「一直在」的安慰合為一體
  4. **手部動作**：「not grasping, only offering」——細節裡的克制感放大情感張力
- **佔位符說明**：`[在此填入角色外觀描述]` = 越小越圓越嬰兒感越好，反差才能爆炸
- **適合場景**：情緒共鳴系列、療癒系帳號、「被理解」主題、節氣感懷、轉給朋友系列
