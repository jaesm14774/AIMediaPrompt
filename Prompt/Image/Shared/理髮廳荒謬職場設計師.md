# 理髮廳荒謬職場設計師

## 中文提示詞

動畫卡通風格插圖，場景為一間佈置精緻的動畫風理髮廳：背景有旋轉紅白藍三色理髮柱、明亮大鏡子、皮革理髮椅與整齊的工具台（梳子、剪刀、吹風機排列一絲不苟）。牆上掛滿裱框的「全國理髮大賽冠軍」證書與獎盃。

[IP角色] 身穿雪白理髮師圍裙、胸口別著金色名牌，手持銀色剪刀，表情極度嚴肅認真，眉頭微蹙，雙眼緊盯客人頭頂，像是在解構一件藝術品；姿勢挺直，散發出「我是頂尖職人」的自信氣場。

客人坐在皮革理髮椅上，脖子圍著白色理髮布，正從大鏡子中看到自己剛完成的髮型——頭髮被定型成一座完美的螺旋錐形高塔，足足有 40 公分高，違反重力地挺立，頂端還自然長出一朵盛開的向日葵；客人的雙眼瞳孔震動成鋸齒狀（動畫慣用的「瞳孔地震」效果），臉頰滾下豆大的冷汗，嘴角劇烈抽搐，下巴因驚嚇差點脫臼，整張臉呈現「人生崩潰」的頂峰表情。

[IP角色] 完全不察覺客人的崩潰，雙手叉腰、仰頭 15 度，嘴角上揚，眼中閃爍著「我完成了一件傳世之作」的滿足光芒。

整體色彩：飽和明亮的動畫調色（橙黃暖光背景、白色圍裙、鮮豔的向日葵黃）。風格：Cartoon Network 誇張表情 + Disney 圓潤線條 + 台灣插畫鮮豔色彩。
