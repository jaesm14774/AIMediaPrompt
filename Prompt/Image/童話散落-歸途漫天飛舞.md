# 童話散落-歸途漫天飛舞
**Fairy Tale Scatter — Homeward Bound Through the Sky**

俯瞰視角中，漫天飛舞的 IP 角色們姿態各異，卻以螺旋方式共同指向畫面中心那個溫暖光點——不是逃跑，是歸家。
